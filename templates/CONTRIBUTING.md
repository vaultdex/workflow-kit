# Contributing

Follow [the shared workflow](.vendor/workflow-kit/docs/CONTRIBUTING.md) and
[engineering rules](.vendor/workflow-kit/WATCHDOG.md). Put project-specific
architecture and build/test commands in `AGENTS.md` and the project documentation.

Write issues and PRs in simple German using the shared
[planning and PR rules](.vendor/workflow-kit/docs/CONTRIBUTING.md#issue-plans-and-pr-descriptions),
including work created without a template. Keep project-owned templates aligned
when updating the kit; generated templates use the existing `init-project` path.
